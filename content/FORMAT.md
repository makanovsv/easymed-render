# Карточка услуги EasyMed — формат (ru — мастер)

Одна карточка = один экран в приложении + сценарий ролика (длинный ~1,5–3 мин и 1–3 Shorts из «вопросов»).
Файл: `cards/<id>.json`, id из `catalog.py`.

| Поле | Что это | В ролике |
|---|---|---|
| `title` | как называет пациент | заголовок |
| `also` | другие названия (для поиска) | — |
| `what` | что это, 1–2 фразы, без терминов | глава 1 |
| `why` | когда назначают | глава 1 |
| `duration` | сколько длится | цифра в кадре |
| `tell_doctor` | что сказать заранее (чек-лист) | глава 2 |
| `prepare` | подготовка: `{title, text}` | глава 3 |
| `bring` | что взять | глава 3 |
| `steps` | как проходит, по шагам | глава 4, шаги в приложении |
| `feel` | что почувствуете — честно | глава 5 |
| `after` | что после, когда результат | глава 6 |
| `red_flags` | когда сразу звонить врачу / в скорую | глава 6 |
| `faq` | частые вопросы `{q, a}` | Shorts |
| `reminders` | `{hoursBefore, text}` — пуши в приложении | — |
| `review` | L / M / H (см. catalog.py) | — |
| `status` | draft → doctor_ok → published | — |

Правила текста:
- Говорим «обычно» и «уточните в клинике» там, где практика разная (время голода, отмена лекарств).
- Никогда не советуем самому отменять лекарства — только «скажите врачу, он решит».
- Без диагнозов, без цен, без названий клиник и брендов препаратов.
- Короткие фразы: одна фраза — один шаг; читается вслух голосом за 3–6 секунд.
- `H` (операции, наркоз) — только черновик, публикуем после врача.
